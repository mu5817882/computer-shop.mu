# Usman Computer Shop

A computer shop website for **Usman Computer** - desktops, laptops, graphics cards, processors, accessories, and repair services.

## Features

- Hero section with a real gaming PC photo
- Product catalog with category filters (Desktops, Laptops, Graphics Cards, Processors, Accessories)
- Working shopping cart (add / remove / quantity) with totals saved in `localStorage`
- Services section
- About section with stats
- Contact form
- Responsive design for mobile and desktop

## How to run

Open `index.html` in any browser. No build step required.

> The hero photo loads from Pexels, so an internet connection is needed to display it.

## Files

- `index.html` - main page
- `styles.css` - styling and layout
- `script.js` - cart, filters, and interactions
- `hero3d.js` - (unused) old 3D hero scene
